# Contributing to trstcode

Thank you for helping improve trstcode. The product may use a private-source model, so opening an issue does not automatically grant access to the application source.

## Ways to contribute

- Report reproducible bugs.
- Suggest developer workflows and UX improvements.
- Improve documentation and translations.
- Test preview builds on macOS, Windows and Linux.
- Submit code after a maintainer has invited you to the private source repository.

## Code contribution flow

1. Open or claim an approved issue.
2. Ask a maintainer for repository access.
3. Create a focused branch.
4. Keep the change small and include screenshots for UI work.
5. Run `npm run build` and `cargo check`.
6. Open a pull request using the repository template.

Unless a separate license or contributor agreement says otherwise, no license to redistribute the private source code is granted.
